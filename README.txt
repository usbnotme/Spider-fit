SPIDER-FIT PWA STARTER

Includes:
- Weekly workout plans (Mon-Fri 20-minute routine, Sat/Sun 5K)
- Checklists saved locally on the device/browser
- 20-minute focus timer
- Calendar reminder export (.ics) with weekly repeating events
- PWA manifest and service worker for install/offline caching

IMPORTANT: To install as a true Home Screen web app, these files must be hosted on an HTTPS website. This ZIP alone cannot create a live website or install directly from Files.

Easy hosting option:
1. Create a GitHub account and a new public repository named spider-fit.
2. Upload all files in this folder to the repository root.
3. In repository Settings > Pages, choose deploy from branch, select main and /(root), and save.
4. Wait for GitHub Pages to publish the HTTPS URL.
5. On iPhone, open that URL in Safari > Share > Add to Home Screen. Enable Open as Web App if shown.

Reminders:
Tap “Add weekly reminders to calendar” in the app, open the downloaded spider-fit-reminders.ics file, and add the events to Apple Calendar. Confirm the alert time in Calendar. Automatic web push notifications are not configured in this starter version.
